## 🌟 核心杀手锏：绝密隐形暗门·私人收藏夹

> **为什么说这是本项目的绝对核心？**  
> 传统浏览器的书签栏不仅杂乱拥挤，而且毫无隐私可言。同事、家人路过或借用电脑时，一眼就能看光你的所有收藏；即使某些扩展带有密码锁，界面上也赫然挂着“私密空间”字样，反而此地无银三百两。  
> **MyTabs 彻底打破这一痛点，打造了真正的“隐形无痕暗门”！**

### 1. 绝密无感伪装（真正的隐形暗门）
* **界面零暴露**：日常状态下，任务栏底栏、分类导航、开始菜单中**彻底抹去私人分类**，绝无任何“私密分类”、“密码锁”按钮或角标。即使旁人紧盯你的屏幕，也只是一张干净优美的新标签页。
* **唯一物理暗门**：**双击桌面中央的时间挂件 / 时钟小组件区域**（即桌面中央显示时间、日期的精美挂件），即可一瞬间唤起主密码解锁弹窗。
* **快捷返回**：身处私人收藏夹时，再次双击时间挂件，即可秒速一键返回常规公共分类。

### 2. 强加密与主密码锁闭
* **端到端零知识加密**：私密网址在本地存储时采用 **Web Crypto API (PBKDF2 强哈希散列 + AES-256-GCM)** 算法强力加密。
* **防破解保证**：即使他人直接拷贝扩展存储或导出 JSON 备份文件，没有你的主密码，看到的全部是经过加密的无规则乱码密文，无法反推任何一个网址。

### 3. 动态独占的私人空间设置面板
* **隐藏式设置项**：在常规分类浏览时，系统设置中**完全看不到**任何关于私人收藏夹的配置项；
* **解锁后专属出现**：**只有在成功输入密码登入私人收藏夹后**，点击左下角的【系统设置】，侧边导航栏才会动态解锁并呈现 **「个人空间锁」专属设置面板**：
  * **主密码管理**：自由修改主密码、清除密码或手动一键立即锁闭。
  * **智能超时自动重新上锁**：离开电脑忘记关网页？支持自定义解锁后的回锁倒计时（预设 **1分钟、3分钟、5分钟、10分钟、15分钟、30分钟** 或手动输入任意分钟数）。倒计时归零后自动退出私人空间并加锁，退回常规分类，保护隐私万无一失。

### 4. 强制无痕隔离与物理零记录
* **脱离浏览器原生书签栏**：私密数据存放于独立沙盒中，在浏览器的书签栏、书签管理器（`Ctrl+Shift+O`）中绝无任何蛛丝马迹。
* **强制无痕窗口打开**：在私人收藏夹内点击任意网站，扩展将强制在 Chrome / Edge 原生**【无痕隐私窗口 (Incognito)】**中拉起，**不留历史记录（`Ctrl+H` 绝无痕迹）**、关窗即刻物理销毁 Cookies 与缓存。

## ☁️ 全网盘本地直存云同步（对网盘没有任何限制）

> **很多用户关心：只能用 OneDrive 吗？可以使用百度网盘、坚果云或其它网盘吗？**  
> **答案是：完全支持任意网盘！对网盘没有任何品牌与类型限制！**

```
 ┌──────────────────────┐         ┌───────────────────────────────┐
 │                      │ 写入文件 │ 本地同步文件夹 (Local Path)     │
 │  MyTabs 浏览器扩展   ├────────>│ 📁 坚果云 / OneDrive / 百度网盘  │
 │ (File System Access) │         │ 📁 Google Drive / Dropbox /NAS│
 └──────────────────────┘         └──────────────┬────────────────┘
                                                 │
                                                 │ 客户端原生自动上传
                                                 ▼
                                  ┌───────────────────────────────┐
                                  │ ☁️ 云端同步（跨设备一键还原）  │
                                  │ (私密网址在云端全部为 AES 密文) │
                                  └───────────────────────────────┘
```

### 1. 原生 File System Access API 架构
* **0 门槛免配置**：无需在第三方开放平台申请复杂的 API Key、Client Secret 或 Token，无需登录中转服务。
* **支持任意网盘与本地目录**：只需在设置中授权绑定一次你电脑上的**任意网盘本地同步文件夹**：
  * **Windows / macOS 常用网盘**：OneDrive、坚果云（Nutstore）、Google Drive、Dropbox、iCloud Drive、百度网盘（同步空间）、阿里云盘（同步盘）、夸克网盘、腾讯微云等；
  * **私有云与本地存储**：群晖 Synology Drive、Nextcloud 本地映射目录，甚至移动硬盘、U 盘或本地任意普通文件夹！
* **毫秒级静默自动保存**：每次添加网址、修改图标或调整布局后，扩展会在后台 1 秒内静默将 `mytabs_backup.json` 写入该目录，网盘客户端会自动秒级同步上云。
* **一键无缝还原**：换电脑或重装系统后，重新授权该文件夹并点击**【从云盘恢复】**，所有分类、网址、图标偏好瞬间原样还原！
* **云端密文无忧**：备份文件中的私人收藏夹内容全部为 **AES-256 高强度密文**，即使上传到任何公共云盘，云盘运营商和第三方也绝不可能窥视到你的真实隐私网址。

### 1. Windows 任务栏风格底栏（Dock）与网址快速搜索定位
* **开始菜单与快速分类**：仿 Windows 11 开始菜单与任务栏药丸，支持在常用推荐、办公效率、影音视听、技术开发等分类间丝滑切换。

* **桌面 24 槽位智能分页与 Dock 联动**：主桌面图标网格支持每页标准 3 行 × 8 列 = 24 个槽位（含新增卡片）独立分页，支持滚轮滚动翻页、左右浮动翻页导航键、键盘左右方向键及拖拽悬停跨页；底栏中间书签 Dock 区域同样支持**鼠标滚轮横向翻页**与翻页按钮，单分类支持容纳海量图标，干净利落。

### 3. 多引擎聚合搜索框
* **快捷轮换**：内置 Bing、Google、百度、GitHub、哔哩哔哩等主流引擎。
* **键盘流体验**：支持输入内容后按键盘 `Tab` 键秒级无感轮换搜索引擎，回车即刻直达。

### 4. 4K 视觉、毛玻璃与 Bing 每日壁纸

* **原生抽屉式侧边栏**：新标签页或任意网页右侧呼出，页面跳转不中断会话。
* **主流模型零障碍接入**：支持 **DeepSeek（推荐，高速聪明）**、OpenAI、Kimi、智谱 GLM、通义千问等所有 OpenAI 兼容 API。
* **网页速读与划词**：网页中右键划词一键“AI 解释”与“AI 翻译”，侧边栏一键结构化提取全文摘要。

### 4. 智能弹窗拦截与隐私模式防御
* **后台标签弹窗封堵**：扼杀网页通过隐蔽 JS 或用户点击空白处触发的后置弹窗（Pop-under）与广告连环轰炸。
* **页面内流氓遮罩清理**：自动识别居中弹窗、强制关注/登录浮层并智能移除，网页滚动条被锁死时自动恢复平滑滚动。

* **【隐私模式协同拦截】**：在无痕窗口下同样生效（开启无痕授权后），且遵循最高零知识防痕规范，绝不记录任何无痕模式下的敏感网址明文！
* **一键网页净化**：点击右上角扩展图标可随时一键净化当前页面的流氓弹窗与遮罩层。

## 📥 安装与加载步骤

本项目为标准 Manifest V3 现代浏览器扩展，适用于 Chrome、Edge、Brave、Vivaldi 等所有基于 Chromium 的浏览器：

1. **打开扩展程序管理页面**：
   * Chrome 浏览器：在地址栏输入 `chrome://extensions/` 并回车
   * Edge 浏览器：在地址栏输入 `edge://extensions/` 并回车
2. 打开页面右上角（或左下角）的 **“开发者模式”**（Developer Mode）开关；
3. 点击左上方的 **“加载已解压的扩展程序”**（Load unpacked）按钮；
4. 在弹出的文件夹选择框中，选中本项目的 `dist` 目录：
   ```text
   D:\work_space\MyTabs\dist
   ```
5. 打开一个新标签页，即可体验 **MyTabs**！

## 🔐 常见问题答疑 (FAQ)

<details>
<summary><b>Q1: 怎么进入私人收藏夹？找不到入口在哪里？</b></summary>

> **A:** 请直接**双击桌面中央显示时间、日期的时钟挂件/图片区域**！这是专为隐私打造的暗门。首次双击可设置主密码，之后双击输入密码即可进入；在私人空间内再次双击时间挂件，即可秒速切回常规公共分类。
</details>

<details>
<summary><b>Q2: 为什么在系统设置里找不到“个人空间锁”的设置？</b></summary>

> **A:** 为了绝对隐形，在常规公共分类下打开设置时，“个人空间锁”选项是完全隐藏的。**只有在双击时间挂件并成功输入密码进入私人收藏夹之后**，再打开【系统设置】，左侧导航栏才会动态呈现【个人空间锁】面板，供您修改密码或调节自动上锁时长。
</details>

<details>
<summary><b>Q3: 同步功能真的可以使用任意网盘吗？</b></summary>

> **A:** **真的没有任何限制！** 扩展使用的是浏览器官方的 File System Access API。无论是 OneDrive、坚果云、Google Drive、Dropbox、iCloud，还是百度网盘、阿里云盘、夸克网盘的本地同步盘，只要在您的电脑上有一个本地文件夹，点击“选择文件夹”授权它即可。扩展会把配置以标准 JSON 保存到那里，由网盘客户端自动同步上云。
</details>

<details>
<summary><b>Q4: 网盘里的备份文件安全吗？私人网址会不会被网盘看到？</b></summary>

> **A:** 绝对安全。私人收藏夹在写入 JSON 之前，已经由 Web Crypto API 使用 **AES-256-GCM** 进行了端到端加密，云盘保存的只是一串完全不可读的乱码密文。没有您的主密码，世界上任何人都无法逆向解密。
</details>

<details>
<summary><b>Q5: 在隐私无痕模式下，弹窗拦截功能可以正常拦截弹窗吗？</b></summary>

> **A:** **完全可以正常拦截！**
> 1. **权限前提**：Chromium 内核对隐私模式默认禁用所有扩展。您只需在浏览器 `chrome://extensions` 中找到 MyTabs 扩展，开启**【在无痕模式下允许】**开关即可。
> 2. **运行机制**：MyTabs 采用 MV3 `spanning` 跨窗口架构，Background Service Worker 与页面内 Content Script 会同步监听无痕窗口中的导航与 DOM 事件，无痕模式下的恶意后置标签页（Pop-under）、全屏遮罩、透明点击劫持均会被毫秒级直接查杀。
> 3. **零知识防痕保证**：普通模式下拦截器支持记录统计，而在无痕模式下拦截时，扩展**严格不记录任何无痕浏览 URL 明文**，只做匿名计数累加，杜绝通过插件记录产生隐私指纹。
</details>
