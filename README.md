# MyTabs - 智能新标签页与多功能工作台浏览器扩展

> 类似 iTab 的现代化高颜值新标签页，集成了资源嗅探（类似猫抓）、AI 侧边栏助手、带锁的私密加密目录、无痕防痕浏览以及 OneDrive 本地直存云同步。

---

## 🌟 核心功能一览

### 1. 自定义高颜值新标签页（iTab 风格）
* **网格与分组**：支持自建分类（常用推荐、开发者、效率办公、影音视听、私密空间等），支持自定义卡片图标、色彩与标题。
* **聚合搜索框**：内置 Bing、Google、百度、GitHub、哔哩哔哩主流引擎，支持一键切换与 `Tab` 快捷键轮换。
* **磨砂毛玻璃与壁纸**：支持 Bing 每日高清壁纸自动更新与极简深色渐变，自由调节背景模糊度与遮罩浓度。
* **极简时钟**：包含实时时钟、动态秒数、公历日期、星期与问候语。

### 2. 资源嗅探器（类似猫抓）
* **多流媒体捕获**：后台自动嗅探当前页面网络请求与 DOM 中的视频、音频、图片及流媒体（支持 `.m3u8`、`.mp4`、`.webm`、`.mp3` 等）。
* **角标实时提示**：扩展图标 Badge 动态显示嗅探到的资源数量。
* **一键复制与下载**：Popup 弹窗直观分类展示，支持直接复制媒体直链或调用浏览器下载器一键保存。

### 3. AI 智能助手（侧边栏 + 右键菜单）
* **原生 SidePanel 侧边栏**：利用 Chrome 原生侧边栏，页面跳转不中断对话。
* **极简 API 接入**：只需填入 API Key 即可使用！预置 **DeepSeek（推荐）**、OpenAI、Kimi、智谱 GLM、硅基流动等主流平台，亦支持任意 OpenAI 兼容的 Base URL。
* **全文速读**：智能提取当前网页核心正文，一键生成结构化摘要与结论。
* **右键划词**：网页中选中文本右键即可呼出“AI 解释”与“AI 翻译”。

### 4. 带密码锁的私密标签页目录
* **端到端零知识加密**：私密分类下的网址在存储时采用 **Web Crypto API (PBKDF2 + AES-256-GCM)** 强加密。
* **访问验证**：进入私密目录需输入主密码，标签页刷新或重启自动上锁。即使导出的配置文件泄漏，没有密码也无法破解。

### 5. 指定网址不留痕迹（无痕与防痕管理）
* **双模式规则**：
  * **模式一（访问后抹除）**：访问指定规则网址后，扩展自动从浏览器历史记录中物理删除该 URL。
  * **模式二（无痕窗口分流）**：在普通窗口打开指定敏感网址时，扩展会自动关闭该页面并在**无痕窗口（Incognito）**中重新拉起。

### 6. 配置备份到 OneDrive（本地授权直存）
* **0 门槛云同步**：通过现代浏览器 File System Access API，只需在设置中授权一次本地的 OneDrive 文件夹。
* **自动静默保存**：每次书签或配置更新后，扩展自动将 `mytabs_backup.json` 写入该目录，Windows OneDrive 客户端会自动将其同步至云端。
* **一键恢复**：随时可一键从云盘读取恢复所有配置，同时支持手动导入/导出 JSON。

## 🚀 安装与加载扩展步骤

1. 打开 Chrome、Edge 或基于 Chromium 的浏览器，在地址栏输入并回车：
   * Chrome: `chrome://extensions/`
   * Edge: `edge://extensions/`
2. 打开页面右上角（或左下角）的 **“开发者模式”**（Developer mode）开关。
3. 点击 **“加载已解压的扩展程序”**（Load unpacked）按钮。
4. 选择本项目构建好的目录：
   ```text
   D:\work_space\MyTabs\dist
   ```
5. 打开一个新标签页，即可体验 **MyTabs**！
